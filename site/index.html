Catalogo de libros

Literalura

Aplicacion de catalogo que consulta Gutendex y guarda autores y libros en PostgreSQL. El dominio no depende de Spring ni de la base de datos.

Como se ejecuta

El sistema completo —aplicacion, PostgreSQL y, en integracion continua, un sustituto de Gutendex— se levanta con Docker Compose. GitHub Pages solo publica esta pagina y no ejecuta la API.

La publicacion ocurre unicamente despues de un push a main con las pruebas unitarias, de base de datos, de integracion y de extremo a extremo en verde. El resto de ramas solo se prueba.
